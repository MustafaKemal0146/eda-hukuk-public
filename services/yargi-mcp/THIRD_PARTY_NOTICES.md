# yargi-mcp — Üçüncü Taraf Bildirimleri

Bu servis (021 §5.16, P11.15) portal istemci davranışını aşağıdaki projelerden **referans alarak**
TypeScript'te yeniden yazar. Kaynak kod kopyalanmamıştır; yeniden kullanılan bilgi uç nokta, istek
parametresi, GUID ve HTML seçici düzeyindedir. Bu bilgi kullanıldığı için MIT bildirimi aşağıda eksiksiz
yer alır.

| Alan | Değer |
|---|---|
| Upstream | `saidsurucu/yargi-mcp` (PyPI) ve aynı yazarın `mevzuat-mcp` projesi |
| Sürüm | 0.2.2 (021 §5.16) |
| Lisans | MIT |
| Telif | Copyright (c) 2025 saidsurucu |
| Lisans dosyası | [`LICENSES/yargi-mcp-MIT.txt`](LICENSES/yargi-mcp-MIT.txt) (depo kopyası: [`third_party/yargi-mcp/LICENSE`](../../third_party/yargi-mcp/LICENSE)) |
| Köken kaydı | [`third_party/yargi-mcp/PROVENANCE.md`](../../third_party/yargi-mcp/PROVENANCE.md) (sdist karması AS-0013) |

`udf_toolkit` lisanssızdır ve hiçbir parçası kullanılmaz; `yargi-sidecar` kodu kopyalanmaz (Y-111).
Servisin npm bağımlılıklarının lisansları kök [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md)
bölüm 1'dedir.
